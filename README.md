# MCU Tracker

An interactive spoiler-free companion for watching the Marvel Cinematic Universe.

Instead of revealing everything from the beginning, the application grows alongside your journey through the MCU.

As you watch each movie or series, the tracker progressively unlocks:

- 🎬 Watch Progress
- 📖 S.H.I.E.L.D. Archive
- 🕸️ Character Connections
- 🌍 Locations & Organizations
- 📅 Timeline
- 🏆 Achievements
- ⭐ Personal Ratings
- 📊 Statistics

Every feature respects your current point in the story, ensuring a completely spoiler-free experience.

---

## Tech Stack

- React
- TypeScript
- Vite
- LocalStorage

---

## Philosophy

> The application should only know what you know.

No character, relationship, location, artifact or event is shown before the user naturally reaches that point in the MCU.
